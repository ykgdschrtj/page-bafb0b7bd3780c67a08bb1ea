品牌简介

本站为咸鱼(XianyuCloud)官方网站。页面提供套餐对照、纵向操作说明、多端客户端选择与下载指引。咸鱼不捆绑闭源自研 App，推荐使用 Clash Meta、Shadowrocket、Stash、v2rayN 等经过社区验证的客户端，导入本站订阅后更新节点即可使用。

线路覆盖香港、日本、新加坡、美国、台湾等常用区域，旗舰与团队套餐提供 IPLC/IEPL 专线与原生流媒体解锁。晚高峰通过多入口与智能分流降低拥堵，适合需要稳定连接的长期订阅用户。

操作说明（纵向五步）

咸鱼(XianyuCloud) 的使用路径刻意做短：选套餐、拿订阅、装客户端、导入、连接。按下面顺序做完，一般即可完成官网推荐流程。

1

确认套餐与设备上限

对照基础版、旗舰版、团队版的流量与同时在线台数。流媒体与游戏优先旗舰版；多人共用或工作室选团队版。

2

获取官方订阅链接

在咸鱼官方渠道完成开通后，复制订阅 URL。请只使用本官网展示的品牌名称咸鱼(XianyuCloud)核对来源，避免导入来路不明的配置。

3

选择并安装客户端

这是本页重点。根据 Windows、macOS、Android、iOS 或 Linux 选择对应客户端，到该软件自己的官方仓库、GitHub Release 或应用商店下载安装包，不要使用来路不明的改装包。

4

导入订阅并更新节点

打开客户端的订阅/Profiles 栏，粘贴咸鱼订阅链接，执行更新。成功后应看到分区节点，如香港、日本、新加坡、美国及游戏专线。

5

测速连接并开启系统代理

选择延迟较低的节点连接，开启系统代理或 TUN 模式。观看流媒体时改用对应地区节点；游戏请优先 IPLC/IEPL 标注线路，并关闭占用带宽的后台下载。

客户端选择与官网下载指引

咸鱼(XianyuCloud) 强调「先选对客户端，再导入机场订阅」。以下为官方推荐组合，下载请走各客户端原厂渠道，本站提供配置与兼容说明。

Windows

推荐 Clash Verge Rev 或 v2rayN。安装后选择订阅管理，粘贴咸鱼链接并更新。需要全局游戏加速时可开启 TUN。下载请使用项目 GitHub Release 页面的正式构建。

macOS

推荐 ClashX Meta 或 Stash。导入订阅后在菜单栏切换节点。Apple Silicon 与 Intel 请下载对应架构。从开发者站点或官方仓库获取安装包，避免第三方镜像。

Android

推荐 Clash Meta for Android 或 Surfboard。允许 VPN 授权后导入咸鱼订阅。分应用代理可把银行与国内 App 直连，减少兼容问题。请从 F-Droid、GitHub 或开发者公布地址下载。

iOS / iPadOS

推荐 Shadowrocket 或 Stash（App Store 付费应用）。安装后新增订阅，粘贴官网提供的 URL。iOS 需在系统设置中允许 VPN 配置。按地区节点解锁对应流媒体。

Linux 与路由器

桌面可用 Clash Meta 内核或 sing-box。旁路由、OpenWrt 可订阅同一链接做家庭网关分流。团队版支持定制路由，把办公网段与游戏设备分开出站。

使用场景

学习与远程资料

访问海外文档、课程平台与开发者仓库时，选择低延迟香港或日本节点，保持会议与下载同时可用。基础版即可覆盖轻度查阅。

流媒体与创作

旗舰版全节点原生解锁，适合 Netflix、Disney+ 等按地区播放的内容。4K 播放请预留足够月流量，并固定使用解锁节点，减少鉴权失败。

游戏加速

IPLC 专线优化针对需要低抖动的对战与更新下载。将游戏进程走加速、语音与启动器按规则分流，避免把全部流量打进一条线路。

小团队协作

团队版 20 台同时在线与 VIP 带宽，适合设计、跨境电商客服与分布式开发。可配合定制路由，让办公网统一出口并保留国内直连。

常见问题

咸鱼(XianyuCloud) 是机场还是自研 VPN App？

咸鱼(XianyuCloud) 是机场订阅服务：官方提供节点与订阅链接，用户在 Clash、Shadowrocket 等客户端中使用。我们不强制安装闭源客户端，这是官网推荐的安全用法。

客户端应该从哪里下载才算官方？

客户端下载以各软件原厂渠道为准，例如 GitHub Release、App Store 或开发者站点。咸鱼官网负责给出选择建议与导入步骤，不会把第三方改装包当作官方下载。

如何判断流媒体有没有解锁成功？

基础版覆盖常见平台的基础解锁；旗舰版与团队版提供全节点原生解锁。若播放报地区限制，请切换到对应国家或地区节点并关闭浏览器代理插件干扰后重试。

设备超限或流量用尽会发生什么？

同时在线超过套餐上限可能被拒绝新连接。月流量用尽后需升级或等待周期重置。团队版适合设备多、流量峰值高的环境，可找专属客户经理调整路由。

游戏延迟仍然高该怎么排障？

先改用旗舰版中的 IPLC 游戏节点，关闭其他大流量任务，并在客户端开启 TUN/增强模式。若仅某个区服高延迟，换邻近区域节点，不要长期使用流媒体专用线路打竞技游戏。

怎样确认自己访问的是咸鱼官网？

认准品牌全称咸鱼(XianyuCloud)，收藏本页并核对套餐价格与客户端说明是否与本文一致。官方不会通过陌生聊天工具索要二次验证码或让你安装未知证书。
